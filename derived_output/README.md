# Derived output

Small tables committed so the figures and reported numbers are available without
rerunning the full pipeline (which needs the CHESS-SCAPE forcing and a multi-hour
HBV run over all 16 scenarios).

**Figure inputs** — required to render the figures listed:

| File | Produced by | Read by |
|------|-------------|---------|
| `responder_table.parquet` | `responder_characterisation.py` | `figures/fig05_projection.py` |
| `borehole_corroboration_clean.csv` | observation-forced corroboration analysis (see below) | `figures/fig04_corroboration.py` |
| `corroboration_summary_final.csv` | observation-forced corroboration analysis | `figures/fig04_corroboration.py`, `figures/fig01_studyarea.py` |
| `hbv_run_summary_45catchments.csv` | observation-forced corroboration analysis | `figures/fig04_corroboration.py` |

**Reported-value tables** — committed for reference; they hold numbers quoted in
the paper and are not read by any script in this repository:

| File | Produced by | Backs |
|------|-------------|-------|
| `recession_timescales.csv` | `recession_timescales.py` | UZ/LZ recession timescales quoted in the SI (Fig. S1 recomputes these from the calibrated parameters) |
| `bootstrap_conditional_gap.csv` | `bootstrap_conditional_gap.py` | Table 1 conditional-gap confidence intervals |
| `si_sensitivity_pairing.csv` | `si_sensitivity_analysis.py` | Supporting Information Table S1 |
| `si_sensitivity_coherence.csv` | `si_sensitivity_analysis.py` | Supporting Information Table S2 |
| `table_s3.csv` | `si_table_s3.py` | Supporting Information Table S3 |

The three corroboration tables are provided as derived data rather than as a
standalone script: they summarise the observation-forced HBV run and the three
borehole tests described in the paper's observational-corroboration methods.

Large intermediates — `slow_full_flow.parquet`, `projection_flow.parquet`,
`forcing_deltas_<rcp>.csv`, and the per-scenario HBV output CSVs — are **not**
committed (see `.gitignore`); they are regenerated by the pipeline.
